## 🔙 如何回滚 (Revert)

如果你觉得新界面不好看，或者有 bug，可以通过以下命令**一键回滚**到修改前的状态：

### 方法 1：回退到"保存点"
我在修改前已经帮你存了一个 Commit。执行这条命令即可完全撤销本次 UI 优化：

```bash
git reset --hard HEAD^
```

*(解释：`HEAD^` 表示回退到上一个版本，也就是我修改前的那个保存点)*

### 方法 2：查看差异
如果你想先看看改了什么，可以执行：

```bash
git diff HEAD^ HEAD
```

---

**⚠️ 注意：** 回滚操作是不可逆的，如果你在回滚后又写了新代码，新代码可能会丢失。建议在回滚前确认没有其他未提交的重要更改。
